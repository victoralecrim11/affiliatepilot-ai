Política de Privacidade

Última atualização: 17 de outubro de 2026

Esta política descreve o estado atual do site do AffiliatePilot AI e as práticas previstas para a futura integração com serviços externos. O projeto está em desenvolvimento e não oferece cadastro ou acesso público ao aplicativo neste momento.

1. Responsável e escopo

O AffiliatePilot AI é um projeto independente de uso pessoal, mantido pelo desenvolvedor identificado em seu perfil público no GitHub. Esta política cobre o site institucional e descreve, separadamente, funcionalidades planejadas do aplicativo. Não há relação de propriedade, representação ou endosso oficial do Pinterest ou do Mercado Livre.

2. Dados coletados pelo site atualmente

Este site é estático, hospedado pelo GitHub Pages. Não contém formulário de cadastro, login, cookies próprios de publicidade, pixels de rastreamento próprios nem coleta intencional de dados pessoais por meio de formulários. A infraestrutura do GitHub Pages pode processar dados técnicos de acesso, como endereço IP e registros de requisições, de acordo com as políticas do GitHub.

3. Integração futura com Pinterest

Se a integração OAuth 2.0 for implementada e autorizada, o aplicativo poderá processar apenas dados necessários às funcionalidades concedidas pelo usuário, como identificador de conta, boards, Pins, metadados e métricas permitidas pela API. Credenciais e tokens de acesso poderão ser armazenados de maneira restrita no ambiente privado de execução do aplicativo, exclusivamente para autenticar requisições autorizadas. A integração ainda não está ativa neste site.

4. Finalidades do tratamento previsto

As finalidades previstas são autenticar o acesso autorizado, consultar boards e Pins, criar Pins após aprovação humana, acompanhar métricas disponíveis, manter histórico técnico mínimo de operações e corrigir falhas de integração. Não há finalidade de vender dados pessoais, criar perfis publicitários de terceiros ou enviar mensagens não solicitadas.

5. Compartilhamento e serviços externos

O site público é hospedado no GitHub Pages. Quando ativadas, as integrações poderão envolver a API oficial do Pinterest, a infraestrutura local de n8n e, para elaboração assistida de conteúdo, provedores de IA configurados pelo responsável. Cada integração dependerá de configuração específica; não afirmamos que tais serviços já estejam ativos. Dados não serão disponibilizados a terceiros para comercialização.

6. Segurança, armazenamento e retenção

O projeto prevê armazenamento privado, permissões mínimas e proteção de tokens e segredos fora de repositórios públicos. Os dados operacionais serão mantidos somente pelo período necessário à finalidade autorizada ou a obrigações aplicáveis. Prazos específicos serão definidos e publicados antes de disponibilizar a integração a outros usuários. Nenhum sistema pode garantir segurança absoluta.

7. Direitos, revogação e exclusão

Quando houver integração OAuth ativa, o titular poderá revogar o acesso pelas configurações de aplicativos conectados do Pinterest. Para solicitar esclarecimentos, acesso, correção ou exclusão de dados eventualmente tratados pelo projeto, utilize o contato abaixo. Não publique tokens, senhas ou outros dados sensíveis em solicitações públicas.

8. Links de afiliados e conteúdo comercial

Conteúdos futuros poderão incluir links de afiliados do Mercado Livre, com identificação de natureza comercial quando aplicável. A navegação por links externos estará sujeita às políticas e práticas dos respectivos serviços. Este site institucional não processa pagamentos nem realiza vendas diretas.

9. Alterações desta política

Esta política poderá ser atualizada conforme as funcionalidades forem implementadas. Alterações relevantes serão refletidas nesta página com nova data de atualização. Antes de liberar autenticação para terceiros, esta política deverá ser revisada para descrever os fluxos reais de dados, contatos, prazos e fornecedores utilizados.

10. Contato

Para questões sobre privacidade, entre em contato com o responsável pelo projeto por meio do perfil público no GitHub. Este é o canal público inicial de identificação do desenvolvedor; um canal privado dedicado deverá ser disponibilizado antes de oferecer acesso a terceiros.
